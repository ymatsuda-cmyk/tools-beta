spaces.json エディタ

全体

default は画面を開いた直後に選ばれるスペース。_note は spaces.json に残すメモで、空なら出力しない。

取り込み元(sources)

一覧JSONとNotionの書き戻し先の組。ID を入れると list / idea の既定値が入る。auto は build_clipstock_json.py が自動生成した印。

スペース(spaces)

取り込み元の組み合わせに名前を付けたもの。URL の ?space=<ID> で選ぶ。mode を空にすると通常の要約向け表示になる。

出力

    問題は見つかりませんでした。
