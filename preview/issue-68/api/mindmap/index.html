マインドマップ原文から構造化して編集する
100%

原文を貼り付けて生成すると、10文字以内の要素に分解します。生成後はノードを直接編集できます。

生成済みのツリーJSONを貼り付けると、AIを使わずそのまま描画します。編集やマーカーの変更は、ここへ自動で反映されます。

原文を入れて「マインドマップを作る」を押してください

API仕様 
ファイル構成

  index.html        画面のマークアップと、このページ固有の配線
  mindmap.css       スタイル
  mindmap.api.js    生成・描画・編集の本体（window.MindMap）

ツリー形式（サーバーAPIのレスポンスもこの形にすると、そのまま描画できます）

  {
    "id": "n1",
    "text": "原文テーマ",        // 10文字以内
    "color": "green",           // purple | green | orange | yellow | pink | 省略で白
    "collapsed": false,
    "children": [ { ...同じ形... } ]
  }

パターン1: 原文からAIで生成する

  MindMap.mount("#viewport");
  MindMap.fromText(原文, { useAI: true }).then(MindMap.render);

  POST https://api.anthropic.com/v1/messages を呼びます。
  自前サーバーを使う場合は mindmap.api.js の callModel() を差し替えてください。
  失敗時はローカル解析に自動で切り替わり、MindMap.lastSource が "local" になります。

パターン2: 生成済みのツリーを渡して表示する

  a) 「作成済みを表示」タブにJSONを貼り付ける
  b) fetch("/api/mindmap?id=123").then(r => r.json()).then(MindMap.render)
  c) 読み込み前に window.MINDMAP_DATA = {...} を定義しておく

そのほか

  MindMap.getData()          現在の編集結果（色の変更もここに入ります）
  MindMap.toJSON()           整形済みJSON文字列
  MindMap.on("change", fn)   編集のたびにツリーを受け取る
  MindMap.on("zoom", fn)     倍率の変化を受け取る
  MindMap.fit() / zoomIn() / zoomOut() / undo()
