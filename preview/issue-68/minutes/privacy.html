プライバシーポリシー

制定日: 2026年9月4日

「アップロード」（以下、「本アプリ」といいます）は、ユーザーの個人情報の保護を重視し、以下のようにプライバシーポリシーを定めます。

1. 取得する情報

本アプリは、Google アカウント連携（OAuth）を通じて、以下の情報を取得する場合があります。

  • アカウントの基本プロフィール情報（ユーザーID、メールアドレス等）
  • 本アプリの機能提供に必要なGoogleサービス上のデータ（ファイル操作・アップロード権限など）

2. 利用目的

取得した情報は、以下の目的でのみ利用します。

  • 本アプリにおけるユーザー認証および本人確認
  • 本アプリが提供するファイル連携・アップロード機能の実行
  • サービスの改善、不具合への対応およびお問い合わせ対応

3. データの保管と第三者提供

  • 本アプリは、法令に基づく場合を除き、ユーザーの同意なしに個人情報を第三者に提供・開示することはありません。
  • Google APIから取得した情報は、本アプリの機能を提供するためにのみ使用され、第三者の広告目的等に転用されることはありません。

4. 外部サービスの利用とGoogle APIポリシーの遵守

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用要件を含みます）に準拠します。
