# 財務ダッシュボード Officeアドイン

事業計画ブックの「月次PL(実績入力)」「月次BS(実績入力)」を読み取り、計画と実績の推移・着地予測・次期計画・決算賞与の試算をタスクペインに表示します。
**Excelのセルを編集すると、その場でグラフと数字が更新されます**（自動更新ON時）。

## 画面構成

| タブ | 内容 |
|---|---|
| 現状 | 通期売上・営業利益・現預金・自己資本比率のKPI。累計売上の計画対比、月次営業利益 |
| 損益 | 月次売上と月次計画、販管費のカテゴリー別積み上げ、利益率推移、費目別の推移 |
| 健全性 | 資産構成と負債、現金預金と売掛金、自己資本比率・流動比率、売掛金回転月数 |
| 予測 | 着地予測（残り月の置き方を調整）と次期計画（成長率・季節性・費用増減）、3期比較 |
| 決算賞与 | 消費税・社会保険料・法人税等を差し引いた賞与前後の利益率、3つの上限、個人別手取り |
| 明細 | 月次PL・月次BSの全科目テーブル、前提と注意点 |

ヘッダー右の**実績確定月**セレクタで、どこまでを実績として扱うかを切り替えます。これより後の月はすべて「見込み」として計算され、グラフでは朱色で表示されます。

## リアルタイム更新の仕組み

- `Worksheet.onChanged`（ExcelApi 1.7）を月次PL・月次BS・前提条件の各シートに登録し、セル編集を検知します。
- ExcelApi 1.8 が使える環境では `Worksheet.onCalculated` も併用し、数式の再計算結果も拾います。
- 連続した編集で何度も読み直さないよう、最後の変更から **600ms** 待って一括で再読み込みします。
- ヘッダーの「自動更新」バッジをクリックすると監視のON/OFFを切り替えられます（OFFのときは更新アイコンで手動読み込み）。
- 再読み込みしてもタブ・スクロール位置・スライダーの設定は保持されます。

## 読み取り仕様

シート名は**前方一致**で探すため、多少の表記ゆれは吸収します。

| シート | 探し方 | 読み取る内容 |
|---|---|---|
| 月次PL(実績入力) | 「月次PL」で始まる | 科目名（A列）・年間計画・12ヶ月の発生額・決算賞与ブロック・みなし仕入率 |
| 月次BS(実績入力) | 「月次BS」で始まる | 科目名（A列）・12ヶ月の月末残高 |
| 36期実績(決算報告書) | 「〇〇期実績」に一致 | 前期の年間実績（科目・金額） |
| 前提条件 | 「前提条件」で始まる | 想定年間売上高・想定年間販管費・売上原価率・期の表記 |

- **月の列は固定していません。** 見出し行にある `2025/10` 形式のセルを探して列位置を決めるので、列を挿入しても、期が変わっても設定変更は不要です。
- **販管費の費目**は、`【販売費及び一般管理費】` の行から `販管費 合計` の行までを自動で拾います。費目を追加しても反映されます。
- 費目のカテゴリー分類（人件費／外注費／地代家賃／販促費／一般管理費／税金・専門家費用）は `dashboard.js` の `CAT_DEF` で定義しています。未定義の費目は「一般管理費」に入れたうえで、明細タブに注記が出ます。
- 科目名の `（旧:外注費）` のような注記は無視して照合します。
- 月次BSの `■検算` 行以降は、同じ科目名が再度出てくるため読み飛ばします。

## 決算賞与の試算

「決算賞与 〇〇さん」という行が月次PLシートにあれば、その氏名と金額を初期値として読み込みます。画面で金額を編集するとその値が優先され、「Excelの金額に戻す」ボタンでシートの値に戻せます。

法人税等は中小法人の標準税率で概算しています（所得800万円以下15%・超過分23.2%、地方法人税10.3%、住民税法人税割7.0%、事業税3.5/5.3/7.0%、特別法人事業税37%、均等割は可変）。事業税の翌期損金算入と繰越欠損金は考慮していません。

## デプロイ手順（GitHub Pages）

1. このフォルダ一式を `tools/addin/zaimu/` として GitHub Pages リポジトリに配置
2. `manifest.xml` をサイドロード、または Microsoft 365 管理センターから組織展開
3. Excelで事業計画ブックを開き、ホームタブの「財務ダッシュボード」ボタンでタスクペインを表示

サイドメニューに載せる場合は、共通の `tools/addin/common/menu.json` のツール一覧に次を追加してください。

```json
{ "id": "zaimu", "label": "財務ダッシュボード", "url": "https://ymatsuda-cmyk.github.io/tools/addin/zaimu/" }
```

## デモモード

`index.html` をブラウザで直接開くと、Excelに接続せずスナップショットデータで全機能を試せます（DEMOバッジ表示）。スナップショットは `demo-data.js` にあり、`gen_demo.py` で事業計画ブックから再生成できます。

## ファイル構成

```

├── manifest.xml     … アドインマニフェスト

├── app.js           … Excel読み取り・変更監視・画面制御

├── gen_demo.py      … スナップショット生成スクリプト
├── style.css        … スタイル

└── icons/           … アイコン
```

## 制限事項

- 金額は税込・試算表ベースです。消費税の発生見込みは営業利益に含めず、決算賞与タブでのみ控除しています。
- 次期計画の月別配分は今期の季節性を使った推計です。過去複数年の月次データを取り込めば精度が上がります。
- 現預金は月次BSに入力済みの最終月を起点にしており、それ以降の入出金は反映していません。
